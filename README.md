### 📌 Featured projects

**🤖 [AI Job-Search Agent](https://github.com/emhw0930/cold-email-agent)** — an autonomous, $0/month job-hunting system
- GitHub Actions pipeline that scrapes job boards daily, ranks **800+ roles** against a résumé with prompt-engineered LLM calls (structured JSON output + keyword fallback), and publishes a live site + top-10 email digest
- **RAG retrieval layer** over résumé bullets to ground personalized recruiter outreach
- Packaged as an **MCP server** with send/bounce/reply tracking over IMAP and a full **audit log** of every agent action
- `Python · MCP · RAG · GitHub Actions · SQLite · Gmail API`

**💬 Real-time Messaging App** — full-stack MERN chat
- Socket.IO real-time messaging with JWT auth, encrypted messages, user search, and persistent sessions
- `React · Node · Express · MongoDB · Socket.IO`

**🗺️ Indoor-Mapping Platform** — internal tool for 1,000+ employees
- Interactive office seat map with editable details, built on the MERN stack and integrated with the Azure Maps Creator SDK for search & navigation
- `React · Node · Express · MongoDB · Azure Maps`
